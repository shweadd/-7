# SKIP / READ / STUDY — быстрый монтаж

Всё уже собрано, ничего не пиши с нуля. Цель — ролик за ≤5 минут.

## Порядок

1. `npm run reel -- путь/к/исходнику.mp4` (опционально `--music=трек.mp3`).
   Скрипт сам: копирует исходник в `public/reels/<slug>/`, транскрибирует (Whisper `small.en`, кэш в
   `~/.cache/reels-whisper`), находит лицо, качает обложки в `public/covers/`, пишет `plan.json`, рендерит
   `out/<slug>.mp4`. Время каждого шага печатается.
2. Проверь вывод: список книг с колонками и `⚠`-предупреждения.
   - `???` в колонке → вердикт не распознан: впиши `"column": "skip"|"read"|"study"` в `plan.json`.
   - Книга не найдена → добавь алиас в `formats/skip-read-study/books.json` (как Whisper её написал,
     смотри `public/reels/<slug>/captions.json`) и перезапусти.
3. Правки плана руками → поставь `"locked": true` в `plan.json`, иначе следующий запуск перезапишет план.
   Перезапуск не транскрибирует заново (кэш `captions.json`), `--retranscribe` — заново.

## Правила формата (не ломать)

- Лицо неприкосновенно: обложки, траектория полёта и субтитры не заходят на рамку лица
  (`face` в плане, считается `scripts/detect-face.mjs`; раскладка — `src/SkipReadStudy/layout.ts`).
  Если лицо не нашлось (`face: null`) — обязательно проверь превью.
- Сверху три колонки SKIP | READ | STUDY; книга появляется «в руках» на названии, улетает после вердикта, whoosh на каждый полёт.
- Первая секунда без музыки (`musicStartSec: 1`), ролик начинается сразу с первой книги (`trimStartSec`).
- Субтитры только на длинных ответах (> 4 слов), слово-вердикт не субтитруется; на личной фразе (I/my/me) — наезд.

## Полезное

- Превью: `npx remotion studio --props=public/reels/<slug>/plan.json`, композиция `SkipReadStudy`.
- Где руки: `hands` в плане (доли кадра), переносится при перепланировании; раскладка всё равно опустит обложку под лицо.
- Новые книги — `formats/skip-read-study/books.json` (`title`, `author`, `aliases`). Обложку можно положить руками:
  `public/covers/<slug-названия>.jpg` или указать `"cover"` у книги.
